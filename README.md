# Portafolio profesional

Portafolio personal en HTML, CSS y JavaScript nativos, basado en el currículum
de Jorge Luis Hernández Colorado.

## Archivos

- [index.html](index.html): estructura, contenido y tipografía Inter de Google Fonts.
- [style.css](style.css): tema oscuro coral, diseño mobile-first y animaciones.
- [script.js](script.js): menú móvil, navegación activa, revelado al desplazarse
  y soporte para animar contadores cuando haya estadísticas documentadas.
- [assets/](assets/): recursos locales.

Abre `index.html` en un navegador moderno. La fuente Inter requiere conexión
a Internet; se usa una tipografía del sistema como alternativa.

El portafolio incluye únicamente datos profesionales presentes en el CV.
No se muestran identificadores personales ni credenciales de acceso. El CV no
incluye perfiles de LinkedIn o GitHub ni un resumen profesional; por eso se
omitieron esos enlaces y la presentación se redactó a partir de la experiencia
documentada. No se añadieron contadores porque el CV no documenta una
estadística de años de experiencia.
